# guest-sdk

The guest runtime: crt0 and `entry!`, the linker script, the allocator, the three memory regions and the delegation shims. Guest-only, outside the workspace.

Specified in [ecall-abi.md](../../docs/spec/ecall-abi.md), [public-values.md](../../docs/spec/public-values.md), [delegation.md](../../docs/spec/delegation.md) §7, §10, [guest-program-manual.md](../../docs/guest-program-manual.md).
