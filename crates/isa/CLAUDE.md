# `crates/isa`

## What this crate owns
The RV32IMAC instruction model: `Instr`, one variant per mnemonic carrying that form's
fields, and `decode` for **expanded 32-bit words**. Nothing else. No dependencies.

```rust
pub enum Instr { Lui { rd: u8, imm: i32 }, /* ... 59 variants ... */ AmomaxuW { .. } }
pub struct DecodeError { pub word: u32, pub reason: &'static str }
pub fn decode(word: u32) -> Result<Instr, DecodeError>;               // FROZEN AT S11

pub struct Fields { pub rd: Option<u8>, pub rs1: Option<u8>, pub rs2: Option<u8>,
                    pub imm: Option<i32>, pub funct3: Option<u8> }
impl Instr {
    pub fn mnemonic(&self) -> &'static str;      // "amoadd.w" -- no aq/rl suffix
    pub fn fields(&self) -> Fields;              // None = the form has no such field
    pub fn aq_rl(&self) -> Option<(bool, bool)>; // the eleven atomics only
}
```

The stage prompt wrote `decode(word) -> Instr`, "roughly", with "define associated error
types"; acceptance 2 wants malformed words to *produce an error*, so the frozen form
returns `Result`.

## Frozen invariants
- **No compressed decoder, ever.** `crates/loader` expands every RVC instruction before
  anything reaches here, and `decode` refuses a word whose low two bits are not `11`.
  One reading of RVC exists in the repository, and it is the loader's.
- **Exactly the 59 RV32IMA instructions**: RV32I's 40, M's 8, A's 11. Every operand field
  may hold any value (`x0` destinations included — that is how RVC HINTs and `nop`
  arrive). Every fixed field must hold its value: `funct7` of the register-register and
  shift-immediate forms, `funct3` of `jalr`, all of `ecall`/`ebreak`, the `.w` width of
  the atomics and `rs2 = 0` of `lr.w`. Everything else is a `DecodeError` naming why.
- **`fence` is the one permissive form, on the ISA's instruction.** Its `rd`, `rs1`, and
  every `fm`/`pred`/`succ` setting are ignored or reserved-as-a-normal-fence ("base
  implementations shall ignore these fields", "shall treat all such reserved
  configurations as normal fences"), so every `MISC-MEM funct3 = 000` word is a fence.
  **This is the one place the decoder is wider than llvm-objdump**, which prints
  `<unknown>` for a fence with a nonzero `rs1` or an unknown `fm`. No compiler emits one;
  the corpus holds only fences both accept, and `tests/sweep.rs` counts exactly the
  `2^22` fences the ISA text defines.
- **An immediate is the value the instruction uses**, as `i32`: sign-extended for I, S,
  B and J; the whole shifted word for U (`lui a0, 1` has `imm = 4096`); the shift amount
  for the three shift immediates. B and J displacements are even by encoding, so a static
  target is always 2-byte aligned — the granularity RVC needs and pc/2 indexing assumes.
  Nothing demands 4-byte alignment.
- **`funct3` in `Fields` is the encoding's `funct3` bits** for every form that has them,
  and `None` for U and J.

## Tests
| File | What |
| --- | --- |
| `tests/objdump.rs` | Acceptance 1. Every instruction of `fib`, `rvc-dense`, `amm` and the hand-encoded corpus is decoded and **rendered in llvm-objdump's own syntax**; the strings must be equal. Compressed lines are rewritten from `c.*` to the base instruction per the RVC chapter and compared with the decode of the loader's expansion — the loader and the decoder together against LLVM's reading of the original halfword. The corpus must decode to exactly the 59 mnemonics, counted from both sides. A perturbed-word negative control. |
| `tests/negative.rs` | Acceptance 2. The committed negative corpus is refused; it covers every format with a fixed field plus foreign encodings; every entry tagged a near miss really is one field from an instruction; and the positive corpus decodes, so refusal is not the default. |
| `tests/sweep.rs` | All `2^30` words with low bits `11`. The accepted count of each of the 32 major opcodes equals a count derived by hand from the ISA tables, and **every accepted word round-trips** through an encoder transcribed in the test from the same tables, and every accepted immediate is in its format's canonical range. Together: `decode` accepts exactly the words the tables name and reads every field from exactly the bits the tables put it in. 0.3 s. |

## Fixtures
`tests/vectors/`, regenerated by `cargo run -p kat-gen -- isa` and diffed in CI, pinned
by SHA-256 in `tests/common/mod.rs`:

| File | What |
| --- | --- |
| `isa_corpus.elf` | 302 hand-encoded words, every RV32IMA mnemonic with register-file ends, `x0`, and boundary immediates |
| `isa_corpus.objdump.txt` | llvm-objdump's reading of it, `--mattr=+m,+a,+c` because a synthetic ELF carries no attributes |
| `isa_negative.txt` | 49 words that must not decode, each tagged with its format and why |

The generator never links this crate: its field encoders make the words and the
disassembler — pinned with the compiler by `rust-toolchain.toml` — says what they are.
The guest listings are `crates/loader`'s, pinned there and read in place.
